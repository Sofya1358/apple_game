# GUI-штурм с TKinter

Гайд по созданию графических приложений на Python с использованием библиотеки **Tkinter**.

## О проекте

Проект состоит из двух частей:

1. **Мини-проект** — небольшое приложение для знакомства с основами Tkinter и Python.
2. **Игра «Собери урожай»** — практический проект, в котором изученные возможности используются для создания простой игры.

Проект разработан в рамках практического занятия по созданию графических приложений.

## Что изучается

В проекте используются:

* переменные и типы данных;
* ввод данных;
* условия `if / elif / else`;
* функции;
* циклы `for` и `while`;
* обработка событий клавиатуры;
* графический интерфейс Tkinter;
* `Canvas`;
* случайные значения;
* таймер `after()`;
* работа с изображениями;
* создание игровой логики.

## 1. Мини-проект

В первом Jupyter Notebook создаётся небольшое приложение, которое помогает разобраться с основами Python и Tkinter.

В приложении используются:

* переменные;
* типы данных;
* поля ввода;
* кнопки;
* условия;
* функции;
* циклы `for` и `while`.

Мини-проект предназначен для того, чтобы сначала разобраться с отдельными элементами программы, а затем перейти к более сложной задаче — созданию игры.

## 2. Игра «Собери урожай»

Во втором Jupyter Notebook создаётся игра, в которой игрок управляет корзиной и ловит падающие предметы.

### Правила игры

* 🍎 яблоко — **+1 очко**;
* 🥫 банка — потеря **1 жизни**;
* пропущенное яблоко — потеря **1 жизни**;
* после потери всех жизней игра заканчивается.

### Управление

| Клавиша | Действие                   |
| ------- | -------------------------- |
| `←`     | Переместить корзину влево  |
| `→`     | Переместить корзину вправо |

### Учебные задания

Игру можно расширить:

**Уровень 1**

* изменить название игры;
* изменить скорость падения предметов;
* изменить размер окна;
* изменить текст окончания игры.

**Уровень 2**

* добавить грушу;
* добавить бомбу;
* изменить оформление игры;
* использовать изображения вместо смайликов.

**Уровень 3**

* сделать постепенное увеличение скорости игры.

**Уровень 4**

* заменить систему жизней таймером;
* сделать игру на время;
* добавить разные значения очков для игровых предметов.

## Как запустить проект

### Python-файл

Для запуска основной программы выполните:

```bash
python main.py
```

### Jupyter Notebook

Для изучения отдельных частей проекта откройте нужный `.ipynb`-файл в Jupyter Notebook или JupyterLab:

* `Untitled.ipynb` — мини-проект;
* `Untitled_game.ipynb` — игра «Собери урожай».

После открытия выполните ячейки с кодом последовательно.
